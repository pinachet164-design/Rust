    Настройки экономики

    Чем выше множитель, тем дешевле сырьё. Цена сырья = базовая ÷ (множитель ^ K).

    0 — цена падает строго пропорционально, 1 — линейно растёт добыча. По умолчанию 0.7.

    Базовая валюта — тугрик. Все цены показываются в ₸, ₽ и скрапе.

    Скрап — не отдельный курс, а пересчёт по цене металлолома. По умолчанию 25 ₸.

    Продажа игроку = себестоимость × (1 + наценка). По умолчанию 25%.

    Доля себестоимости, которую получает игрок. По умолчанию 45%.

    По умолчанию 55%.

    Остальные категории. По умолчанию 67%.

    «Сохранить таблицу» — файл rust-economy.json со всей таблицей: названия, категории, базовые цены, рецепты и разборка, плюс настройки и ручные цены. «Загрузить таблицу» возвращает такую же выгрузку обратно в сайт, поэтому дальше таблицу можно вести только здесь. CSV — только для чтения в Excel, обратно он не загружается.

    Настройки, загруженная таблица и ручные цены сохраняются в localStorage этого браузера.
